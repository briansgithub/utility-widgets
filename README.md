# Utility Widgets (FloatPlay)

Android app that keeps floating buttons on screen over other apps:

- Play / pause for the active media player
- Toggle the system Auto-rotate screen setting
- Brightness dial: turn clockwise or counterclockwise to adjust 0–100%; turning selects manual brightness. Tap to toggle automatic brightness. Double-tap and hold the second tap, then drag to move the dial. Its position is saved.

Launch the app to enable or disable each floating widget. It needs permission to display over other apps. Auto-rotate and brightness also need permission to change system settings. A notification stays visible while the overlay is on.

Package: `com.floatplay.overlay`  
Min SDK: 30
